# Project Milestones

This directory tracks the major milestones for the AeonFlux Backend project.
Currently planned milestones:

*   **M1: Scaffolding & Setup** (Current) - Initialize documentation structure, build scripts, static linters, and spring configurations.
*   **M2: Validation Worker & Queues** - Implement cloud task enqueuer and feed validation job parsing (XML/RSS parsing).
*   **M3: Ingestion & Datastore** - Connect repositories to Google Cloud Datastore and index feeds.
